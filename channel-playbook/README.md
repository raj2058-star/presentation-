# Tomorrow's Record: the channel playbook

A faceless YouTube documentary channel about the next 10–100 years, built on the research in
`../youtube-research/faceless-channel-plan-2026-2036.md`. This folder takes it from **nothing** to
**six months of publishing** (16 Nov 2026 – 31 May 2027).

Everything here was made with the YouTube agent skill pack: hooks scored by `/yt-script`, titles and
thumbnails linted by `/yt-package`, and the schedule shaped by `/yt-plan`.

## What you do next (this week)

1. Claim **@TomorrowsRecord** and set up security (`01`, steps 1–2).
2. Build the brand kit (`01`, step 3).
3. Read EP01's two sources, fill in the `[VERIFY]` and `[READ FROM REPORT]` markers in the script, then record it.
4. For each later episode, run `/yt-script` with its package from `04` and its research to write the full script.

## What this playbook can't do for you

- **It can't guarantee views.** It gives you repeatable odds, plus rules for doubling down when something works.
- **It doesn't contain the research for EP02–EP12.** Each package lists the sources to read, and every number in a script must come from them.
- **YouTube changes its menus and rules.** Check the monetization numbers in Studio → Earn, and the AI disclosure rules in YouTube's Help Center.
